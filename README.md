# Pediatric Clinic Database Management System

## Short Description

Developed a relational database model for a pediatric clinic with a focus on creating a sub-schema for issuing sick leaves and medical excuses. Designed and implemented key database elements including DML, DDL, triggers, and procedures to support clinic operations.

## Key Bullet Points

- Designed and implemented a relational database schema for a pediatric clinic to manage patient records, appointments, and medical documentation.
- Focused on developing a sub-schema for issuing sick leaves and medical excuses, automating workflows and ensuring accuracy.
- Utilized DML and DDL for data manipulation and structure, along with triggers and stored procedures to automate and enforce business rules.
